# ParallelAgent 单轨（solo）

## 依赖

- `~/.parallel-agent/references/分流.md`（判据）
- `~/.parallel-agent/references/台账.md`（台账规则）
- `~/.parallel-agent/references/协议.md`（字段与命名）
- `~/.parallel-agent/templates/`（分流卡、任务卡、台账条目、交接手册）

缺失时先提示用户运行 `npx parallelagent@latest init`，不要凭空猜规则。

**被问及协议、字段、流程时**：直接读上述文件回答，**不要凭记忆**，也不要假设其他 Skill 的正文已加载（Skill 正文按需加载，未调用时只可见名称与描述）。

## 流程

1. **判定 fail-stop**：破坏性、不可逆、范围不明 → 停机提问，不继续
2. **分流**：按 `分流.md` 判 L0-L4，输出分流卡（L0 可略）
3. **按等级执行**：

| 等级 | 动作 |
|---|---|
| L0 | 直接改 → 跑验证 → 写台账 |
| L1 | 一次问一个（≤3 问，带推荐项）→ 答案入台账 → 执行 → 写台账 |
| L2 | 写任务卡与 2-3 个候选方案 → 请用户选 → **不写业务代码** |
| L3 | 写任务卡 → 用户确认验收 → 执行 → 逐条核对 → 写台账 |
| L4 | 写任务卡 + 分流卡（含强拆条件核对）+ 交接手册（开轨前版）→ 移交仲裁者 |

4. **落台账**：行为变更遵循「先提交代码 → 再写台账并回填真实 hash」
5. **收尾**：输出一句话结论（改了什么、证据、遗留）

## 红线

- L4 只做决策与文档，**不建轨道、不派子代理**
- 不代写回执（回执属于轨道）
- 台账只追加，不改历史条目
- 没有证据（命令与输出）不得宣称完成

## 交接给仲裁者

L4 时交接内容是**文件**，不是长文本：

- `任务卡` 路径
- `分流卡` 路径（含强拆核对）
- `交接手册` 路径
- 一句话：「拆 N 轨，执行器按能力档案」
