# 能力档案：<宿主名>

安装位置：`~/.parallel-agent/能力档案/<host>.md`（全局，每宿主一份；项目级覆盖另存 `.parallel-agent/能力档案.md`）。

填写规则：

1. 本文件只由 Agent 写入；CLI 只读不写
2. `confidence`：`实测`=真跑过 P1-P6；`自述`=读工具清单；`未验证`=未测
3. 降级决策按最低可信度：`未验证` 等同于缺失；`自述` 不得用于并发类判断
4. `schema_version` 与「能力档案-模板」结构版本一致，不一致视为失效
5. `max_concurrency` 未知时填 `1`（退化为串行）
6. `notes` 记录原始报错（例如并发超限的原文）

探测用例与判定见设计文档 §4.3（P1-P6）。探测一律在临时目录进行，测完清理。
