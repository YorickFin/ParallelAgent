# 分流判据（L0-L4）

入口只有一件事：判断这次请求走单轨还是多轨。

---

## 1. 等级定义

| 等级 | 名称 | 判据 | 必产 |
|---|---|---|---|
| L0 | 直做 | 目标一句话说清；单文件或单点；低风险 | 台账条目 |
| L1 | 问清 | 目标明确，但关键参数未定（≤3 个问题） | 台账（含问答） |
| L2 | 探路 | 概念清楚、结构未定；不写业务代码 | 任务卡 + 台账 |
| L3 | 立规 | 目标明确、规模中等、需先定验收再改码 | 任务卡 + 台账 |
| L4 | 多轨 | 满足全部强拆条件 | 任务卡 + 分流卡 + 交接手册 |

---

## 2. 判定顺序

1. 是否命中 **fail-stop**（破坏性、不可逆、范围不明）→ 停机并提问，不进入后续判定
2. 是否满足 **L4 强拆条件**（§3）→ 是则 L4
3. 是否需要先定方案再动码 → L2
4. 是否需要先定验收再动码 → L3
5. 是否有关键参数未定 → L1
6. 其余 → L0

---

## 3. L4 强拆条件（全部满足才拆）

| 条件 | 判据 |
|---|---|
| 边界正交 | 各轨 `scope` 无交集（重叠 0%） |
| 可独立验收 | 每轨有独立验收命令或判据 |
| 风险不耦合 | 任一轨失败不阻塞其余轨验收 |
| 有收益 | 并行收益 > 契约编写 + 实检成本 |
| 能力可用 | 能力档案 `max_mode` 含 L4，`max_concurrency ≥ 2` |

不满足任一条 → 降为 L3 单轨执行。

---

## 4. 各等级的产出要求

### L0

- 直接改，改完写台账
- 不做任务卡、不建轨道

### L1

- 一次问一个，带推荐项与选项，最多 3 问
- 问题与答案写入台账

### L2

- 写任务卡：目标 / 非目标 / 未知项 / 假设 / 候选方案 / 验收
- 本阶段**不写业务代码**

### L3

- 写任务卡 → 用户确认验收 → 执行 → 逐条核对 → 写台账
- 任务卡必须先确认后动码

### L4

- 写任务卡 + 分流卡（含强拆条件核对）
- 写交接手册（开轨前版）
- 移交仲裁者执行，按生命周期方案推进

---

## 5. fail-stop 情形

- 删除、重置、覆盖类不可逆操作且范围不明
- 找不到锚点或契约版本不一致
- 越界扫描命中且无法确认归属
- 能力档案 `max_mode` 不支持当前请求

fail-stop 时：**停止执行 → 说明原因 → 提问范围**，不产生任何破坏性改动。
