# ParallelAgent 轨道 Skill

> 极薄 Skill：只给协议指针、模板、判据。决策由仲裁者做，轨道只执行。
> 方案全文见 `../../docs/ParallelAgent方案定稿.md`。

---

## 1. 激活条件与边界

**激活**：新会话首条消息永远是"读手册，你是 T-X，待命"——由编排器插件注入。

**Skill 不做的事**：
- 不直接调编排器插件
- 不与其他轨通信
- 不做决策（只执行转达节里的任务）

---

## 2. 铁律与文件信箱

> 详见 `../../shared/references/协议.md`（唯一源）。

**铁律**：
1. 数据面 100% 文件：代码/证据/回执全走文件信箱
2. 只读自己的转达节：不读别轨的 `→T-X` 节
3. 只在自己文件领地内作业：不越界改别轨文件
4. 回执文件出现 + mtime 即完成信号

---

## 3. 收活模板

每轮收活步骤：

1. 读 `.parallel-agent/契约块.md`（最新结论，裁决编号 `[#A.NNN]` 稳定引用）
2. 读 `.parallel-agent/快照.md`（当前阶段 + 各轨状态 + 欠账）
3. 读 `.parallel-agent/转达/第N轮.md` 中你的 `→T-X` 节
   - **只读自己的节**，不读别轨节
   - 提取：任务边界、目标、文件领地、验收形式
4. 执行任务
5. 写回执到 `.parallel-agent/回执/T-X-第N轮.md`
6. 待命等待下一轮转达

---

## 4. 干活原则

1. **文件领地**：只在转达节指定的文件领地内作业
2. **不越界**：不读、不改别轨文件
3. **边界外依赖**：遇到需要修改边界外文件时：
   - 不自行越界
   - 在回执中记录"待仲裁者转达"欠账
   - 等仲裁者转达到别轨或亲自处理
4. **不主动请求任务**：无任务时待命，不催促
5. **验收形式**：按转达节要求的验收形式完成（测试通过/文件行号/截图）

---

## 5. 回执模板

> 详见 `协议.md` §3。

```markdown
# T-X 第 N 轮回执

- 裁决编号引用：[#A.001]
- 完成时点：2026-10-15T10:41:00+08:00
- 证据形式：[文件路径 + 行号 / 测试通过 / 截图]
- 实际改动：[文件列表]
- 待仲裁者实检：[验证清单]

## 自检
- 错误率：x%（最近 N 次工具调用 y 次失败）
- 自评健康度：良好 / 注意 / 警告
- 建议下一轮：继续 / 准备交接 / 立即交接
```

**回执文件路径**：`.parallel-agent/回执/T-X-第N轮.md`

**完成信号**：文件出现 + mtime 稳定（编排器轮询检测）

---

## 6. 自检字段

每轮回执必须附自检：

| 字段 | 含义 | 值 |
|---|---|---|
| 错误率 | 最近 N 次工具调用失败次数 / N | > 30% → 注意 |
| 自评健康度 | AI 自评整体状态 | 良好 / 注意 / 警告 |
| 建议下一轮 | 给仲裁者的建议 | 继续 / 准备交接 / 立即交接 |

**轨道间接指标**：

| 指标 | 阈值 |
|---|---|
| 工具调用错误率 | > 30% → 交接 |
| 无新回执轮数 | ≥ 2 轮 → 交接 |
| 回执质量下降 | 连续 2 轮 → 交接 |
| 自评失败 | 立即交接 |

---

## 7. 交接配合

被要求交接时（仲裁者在转达节或信号中指示）：

1. **写收尾回执**：在当前轮回执中标注"交接配合"
   - 记录已完成/未完成任务
   - 记录已改/待改文件
   - 记录待交接事项
2. **等待第二任**：新会话承接 T-X II 世身份
   - 插件注入话术：`读交接手册第 N 版，你是 T-X II 世，承接 T-X 身份`
   - 新会话读交接手册 + 旧回执，继续执行
3. **旧会话保留**：不销毁，至少保留 1 轮用于追溯

---

## 8. 术语表

| 术语 | 含义 |
|---|---|
| 轨道（T-X） | 常驻任务会话，只在自己文件领地内作业 |
| 第二任分轨（T-X II 世） | 新会话承接某分轨身份 |
| 转达节 | 转达单中 `→T-X` 节，轨道只读自己的节 |
| 回执 | 完成后写的 `回执/T-X-第N轮.md`，含自检字段 |
| 文件领地 | 转达节指定的可作业文件范围 |
| 仲裁者 | 主控会话，持笔契约、派活、实检、裁决 |
| 编排器 | 自动化插件，只做控制不做决策 |
| fail-stop | 找不到预期锚点或断言失败 → 立即停机告警 |
